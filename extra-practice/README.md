# 낯선 표로 해 보기 — 도서관 이용

5–8장을 마친 뒤 풀어 보는 선택 과제입니다. 본문의 매출 자료와 별개인 **교육용 가상 자료**입니다. 먼저 이 문제를 풀고 `solution.py`를 엽니다.

`visits.csv`에는 두 도서관 분관의 사흘 동안 이용 건수와 개방 시간이 있습니다. `day`는 조사일 번호, `site`는 분관, `visits`는 이용 건수, `open_hours`는 개방 시간입니다. 이용 건수는 사람 수와 다릅니다. 같은 사람이 여러 번 이용했을 수 있습니다.

질문은 **“사흘 전체에서 개방 1시간당 이용 건수가 더 많은 분관은 어디인가?”**입니다.

1. 표의 한 행이 무엇을 뜻하는지 적고, 비교할 기간·집단·단위를 밝힙니다.
2. 열의 형식, 비어 있는 값, 중복 관측, 0 이하 개방 시간이 있는지 확인합니다.
3. 질문에 답할 집계식을 먼저 적습니다. 분관별 이용 건수의 합계만 비교하거나 일별 비율을 단순 평균해도 되는지 이유를 씁니다.
4. 차트를 골라 두 분관을 비교합니다. 제목·축 단위·출처를 적고, 그림의 값 한 곳을 표에서 따로 계산해 맞춰 봅니다.
5. 관찰과 한계를 각각 한 문장으로 씁니다. 이용률 차이를 서비스 품질이나 운영 성과로 단정할 수 있는지도 생각해 봅니다.

완료 기준은 다음과 같습니다.

- 한 행의 뜻과 이용 건수·사람 수를 구별했다.
- 사흘 전체의 질문에 맞는 분자·분모를 같은 범위에서 집계했다.
- 차트에 시간당 이용 건수의 단위가 있고, 원표 검산값과 같다.
- 그림의 관찰을 숫자로 설명하고, 가상 자료·짧은 관측 기간의 한계를 밝혔다.

풀이가 끝나면 `solution.py`의 검산값·해석과 대조합니다. **단순 평균을 쓴 답이 왜 질문과 어긋나는지 설명할 수 있어야 합니다.** 풀이의 그림은 한 가지 선택 예이며, 같은 비교를 정확하게 전달하는 다른 차트도 가능합니다.

풀이를 실행하려면 예제 폴더에서 다음 명령을 씁니다. 현재 폴더에 `transfer_output.png`가 만들어집니다. 그림은 글꼴 설치 없이 실행하도록 영어로 표시합니다.

```bash
python extra-practice/solution.py
```
