# 13개 장의 목표·실습·확인 증거 지도

현재 읽는 장이나 다시 확인할 개념을 찾습니다. 대표 실습은 본문의 기존 W 번호이며, 여기서 새 과제를 추가하지 않습니다. ‘확인 증거’는 실행 성공과 함께 남겨야 할 원자료 대조·저장본·설명입니다. 재독 위치는 본문 절 번호입니다. 전체 노트북의 실행 방법은 [예제 안내](../README.md)를 봅니다.

## 1장 시각화의 목적과 실습 준비

목표: 질문과 차트를 연결하고 한글·단위를 갖춘 첫 차트를 검수합니다.

기존 실습·산출물: W1-01의 B지점 차트, W1-02의 질문 한 문장·유형·필요 열 두 개.

확인 증거: B지점 원래 값과 차트의 값이 같고 단위가 보인다. 질문에 필요한 열과 차트 종류를 설명한다.

재독: 1.1절 ‘시각화는 질문에 답한다’, 1.4절 ‘첫 차트 그리기’, 1.5절 ‘AI 초안 점검하기’, 1.6절 ‘해석과 점검’.

## 2장 Matplotlib 기초

목표: Figure·Axes·Axis를 구별해 단일 차트를 완성하고 저장합니다.

기존 실습·산출물: W2-03의 객체별 주석과 PNG, W2-04의 오류 원인과 최소 수정.

확인 증거: 각 명령의 대상 객체를 설명한다. 저장본에 기간·단위가 보이며 잘림이 없다. 오류 네 줄을 따로 판단했다.

재독: 2.2절 ‘Figure·Axes·Axis의 구조’, 2.4절 ‘단일 차트 완성과 저장’, 2.5절 ‘변환 실습과 오류 점검’. 개념 확인 Q01.

## 3장 Matplotlib 응용

목표: 비교 목적에 맞게 여러 Axes를 배치하고 축 공유 여부를 설명합니다.

기존 실습·산출물: W3-03의 매출·영업이익 그림, W3-04의 2×2 종합 그림과 비교 설명.

확인 증거: 저장본의 패널과 지표가 대응한다. X축 공유와 Y축 분리의 이유, 높이로 직접 비교하면 안 되는 대상을 설명한다.

재독: 3.2절 ‘Axes 배치와 접근’, 3.3절 ‘축 공유와 공정한 비교’, 3.4절 ‘제목·범례·레이아웃’, 3.5절 ‘종합 실습과 오류 점검’. 개념 확인 Q01.

## 4장 Seaborn 기초

목표: 긴 형식 표의 열·색상 그룹·요약값을 차트에 연결합니다.

기존 실습·산출물: W4-02의 평균·오차 표시 설명, W4-03의 합계 막대와 비교 문장.

확인 증거: `hue`와 오차 표시가 바꾸는 것을 구별한다. 지점별 합계를 따로 계산한 표와 막대가 같고, 평균과 합계의 차이를 단위와 함께 설명한다.

재독: 4.1절 ‘표의 열과 차트 연결’, 4.2절 ‘색상 그룹과 요약값’, 4장 C07·C10. 개념 확인 Q02.

## 5장 Seaborn 응용

목표: 질문에 맞는 차트를 고르고 관찰과 원인 주장을 구별합니다.

기존 실습·산출물: W5-03의 차트 선택·차이 계산, W5-04의 히트맵과 관찰·한계·추가 확인 문장.

확인 증거: 고른 차트가 상품 비교 질문에 답하며 별도 차이 계산과 맞는다. 히트맵의 관찰을 원자료와 대조하고 확인하지 않은 원인을 단정하지 않는다.

재독: 5.2절 ‘산점도와 집단 구분’, 5.4절 ‘비중과 크기 비교’, 5.5절 ‘차트 선택의 검수와 해석’. 개념 확인 Q03·Q04.

## 6장 차트 다듬기 I

목표: 색·축·눈금·단위·주석을 데이터와 목적에 맞게 다듬습니다.

기존 실습·산출물: W6-03의 바뀐 자료에 따라 갱신한 주석, W6-04의 3→4월 변화 계산·비교 차트·저장본.

확인 증거: 자료를 바꾸면 주석 위치·값도 함께 바뀐다. 따로 계산한 변화량과 차트가 같고 제목·단위·출처를 저장본에서 확인했다.

재독: 6.3절 ‘축·눈금·단위’, 6.4절 ‘주석과 기준선’, 6.5절 ‘최종 차트와 동료 검수’. 개념 확인 Q05.

## 7장 차트 다듬기 II

목표: 초안의 문제를 근거로 고치고 검수 기록과 한 장 보고서를 만듭니다.

기존 실습·산출물: W7-03의 문제·근거·수정·재확인 세 행, W7-04의 영업이익 보고서·해석·검수 기록.

확인 증거: 고친 코드와 별도로 계산한 합계가 그림과 같다. 그대로 둔 설정의 근거를 말하며 저장본의 범례·배치·단위를 확인했다.

재독: 7.1절 ‘질문과 검수 순서’, 7.4절 ‘스타일 재사용과 AI 초안 검수’, 7.5절 ‘한 장 보고서와 동료 검수’.

## 8장 분포 읽기

목표: 구간·밀도·박스 플롯으로 분포를 비교하고 요약의 한계를 설명합니다.

기존 실습·산출물: W8-01의 구간 폭 비교·건수 검산, W8-02의 예측과 정규화 비교, W8-03의 울타리·수염·삭제 전 확인 기록.

확인 증거: 구간 건수의 합이 전체 관측 수와 같다. 복제는 새 관측이 아님을 밝히고 밀도만으로 건수를 말하지 않는다. 계산한 울타리와 실제 관측의 수염을 구별한다.

재독: 8.2절 ‘히스토그램의 구간’, 8.3절 ‘밀도로 집단 비교’, 8.4절 ‘박스 플롯과 이상치 후보’. 개념 확인 Q06·Q07.

## 9장 Plotly 기초

목표: 툴팁·확대로 원자료를 확인하고 HTML로 저장합니다.

기존 실습·산출물: W9-02의 겹친 두 점 대조, W9-03의 평균표와 강조 막대, W9-04의 HTML·관찰·추가 확인 문장.

확인 증거: 툴팁의 두 행이 원자료와 같다. 막대가 평균표와 일치하고 제목도 평균을 나타낸다. 새로 연 HTML에서 툴팁·숨김·확대·복원이 된다.

재독: 9.2절 ‘산점도·툴팁·평균 집계’, 9.3절 ‘Figure 구조와 수정’, 9.5절 ‘HTML 저장과 공유’. 개념 확인 Q08.

## 10장 Plotly 응용

목표: 날짜 축·서브플롯이 있는 HTML 리포트를 만들고 표시 범위와 집계를 구별합니다.

기존 실습·산출물: W10-03의 확대·4분기 재집계 기록, W10-04의 리포트와 파일 검사 결과.

확인 증거: 툴팁을 원자료와 대조했고 4분기 행 수·합계를 따로 계산했다. 연간 합계는 확대 뒤에도 그대로이며, 새로 연 리포트의 세 차트는 독립적으로 조작된다.

재독: 10.3절 ‘날짜 축과 범위 탐색’, 10.4절 ‘HTML 리포트 조립’, 10.5절 ‘리포트 검수’. 개념 확인 Q09.

## 11장 Streamlit

목표: 같은 선택 결과를 카드·차트·표·CSV에 연결하고 오류를 진단합니다.

기존 실습·산출물: W11-01의 첫 화면 검산, W11-03의 오류 재현·복구 기록, W11-04의 내려받은 CSV.

확인 증거: 선택 조건별 별도 계산이 카드와 같다. 막대가 다른 표를 쓸 때의 차이를 재현하고 복구했다. CSV의 행·값이 화면과 같고 파일명에 선택 조건이 들어간다.

재독: 11.3절 ‘차트와 표 연결’, 11.4절 ‘검산과 오류 진단’, 11.5절 ‘직접 수정과 선택 확장’. 개념 확인 Q03·Q10.

## 12장 공공데이터 API

목표: 받은 자료 또는 저장본의 형식·범위를 점검하고 질문에 맞게 그립니다.

기존 실습·산출물: W12-01의 지점별 행 수·기간·강수 점검, W12-02의 계절 합계 그림, W12-04의 수정·확인 기록.

확인 증거: 강수 여부로 나눈 날의 합이 행 수와 같다. 계절 합계의 합이 연 강수량과 같다. API 성공과 키 없음·실패 시 저장본 사용을 구별하고, 행 수·기간·숫자 형식을 확인했다.

재독: 12.2절 ‘요청과 응답’, 12.3절 ‘형식 바꾸기와 점검’, 12.4절 ‘질문에 맞는 차트 셋’, 12.5절 ‘실패 메시지와 AI 초안 검수’. 개념 확인 Q11.

## 13장 프로젝트

목표: 자기 질문과 공개 자료로 점검·차트·검수·앱·배포·발표를 완성합니다.

기존 실습·산출물: W13-01 카드, W13-02 계획표·차트 셋·해석, 13.3절 네 칸 검수 기록, W13-03 검산표·배포 주소, W13-04 발표자료.

확인 증거: 13.6절의 질문·데이터, 차트·해석, 대시보드·배포, 발표·질의응답 네 항목을 산출물로 판정한다. 원자료 대조 수치·선택 조건별 검산·다른 브라우저 확인·4분 이내 연습·예상 질문 두 개의 답변 근거가 남는다.

재독: 13.1절 ‘질문과 데이터’부터 13.6절 ‘해석과 점검’까지. 개념 확인 Q12와 [프로젝트 기록 양식](project-template.md).
