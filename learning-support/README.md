# 학습지원 자료 안내

『AI 시대의 파이썬 데이터 시각화』의 개념 확인과 13장 프로젝트 기록을 위한 보조 자료입니다. 본문의 기존 W 연습과 완료 기준을 함께 사용합니다.

## 읽는 순서

1. [개념 확인 12문항](concept-checks.md)에서 판단과 이유를 적고 변형 재도전도 먼저 풉니다. 전체 문항은 13.1절까지 읽은 뒤, 개별 문항은 표시된 선수 절을 읽은 뒤 풉니다.
2. [해설과 재도전 답](answers.md)을 열어 판단뿐 아니라 계산·이유를 대조합니다. 이유가 다르면 지정한 절과 기존 실습으로 돌아갑니다.
3. [프로젝트 기록 양식](project-template.md)을 복사해 W13-01~W13-04와 13.3절의 기록을 채웁니다. 13.6절의 기존 네 항목으로 산출물을 확인합니다.
4. [13개 장의 학습 지도](learning-map.md)에서 현재 목표·대표 실습·확인 증거·재독 위치를 찾습니다.

## 파일과 형식

| 파일 | 용도 |
|---|---|
| [concept-checks.md](concept-checks.md) | Q01~Q12 문제·응답칸·변형 재도전 질문 |
| [answers.md](answers.md) | 같은 번호의 판단 답·근거·오답 이유·재독·재도전 답 |
| [project-template.md](project-template.md) | 복사해 채우는 프로젝트 기록 양식 |
| [project-template.ipynb](project-template.ipynb) | 노트북에서 편집하는 같은 프로젝트 기록 양식 |
| [learning-map.md](learning-map.md) | 13개 장의 목표와 기존 W·확인 증거 연결 |
| [study-guide.pdf](study-guide.pdf) | 문제 뒤에 해설을 분리한 읽기·필기용 묶음 |
| [index.html](index.html) | 제목·목차·링크로 이동하는 HTML판 |

Markdown과 노트북의 대괄호는 독자 작성칸입니다. 완성 프로젝트나 새 배점표가 아닙니다. 노트북 양식은 기록용이며, 실제 분석 코드는 본문 실습과 자기 프로젝트에서 작성합니다. PDF에 필기하거나 편집 파일을 복사해 기록합니다.

12문항은 설치·인터넷·인증키 없이 제시된 가상 사례만으로 풉니다. 12장 실제 기상 저장본과 새 문항의 가상 API 응답은 서로 다른 자료입니다. 예제 실행 환경과 저장본 사용 순서는 [상위 예제 안내](../README.md)를 봅니다.

온라인에서는 Markdown 파일을 바로 읽습니다. HTML판은 내려받은 폴더의 `index.html`을 엽니다.
